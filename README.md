# Gym Project — мобильное приложение фитнес-сети

Клиентское приложение сети тренажёрных залов в духе FitnessBlitz / Fitnation / 1Fit:
абонемент, QR-вход, расписание групповых, запись к тренерам, загруженность клубов, прогресс.

Стек: **Expo SDK 57 · React Native · TypeScript · Expo Router**. Работает на iPhone и Android.

## Экраны

| Экран | Что умеет |
| --- | --- |
| Вход | Телефон + SMS-код (демо-код `1234`), имя |
| Анкета | Цель (похудеть, масса, форма, сила, гибкость), пол, возраст, рост, вес, целевой вес, уровень, тренировок в неделю; ИМТ считается на лету. Данные используются на главной, в профиле, прогрессе и магазине |
| Главная | Карточка абонемента с днями до конца, QR-пропуск, быстрые действия, ближайшие записи, загруженность клубов, новости |
| Клубы | Поиск, фильтр по городу, избранное, загруженность в реальном времени, 24/7 |
| Клуб | Фото, маршрут, звонок, инфраструктура, занятия сегодня, тренеры клуба, «сделать домашним» |
| Расписание | Лента дат на 14 дней, фильтры по клубу и направлению, свободные места |
| Занятие | Тренер, клуб, уровень, места, запись / отмена, лист ожидания |
| Тренеры | Поиск, специализации, рейтинг, цена; запись на персональную тренировку |
| Магазин | Спортпит, витамины, батончики, напитки, аксессуары, одежда; категории, поиск, сортировка, хиты |
| Товар | Фото, цена и цена по абонементу, вкус/размер, пищевая ценность, похожие товары, корзина |
| Корзина | Количество, клуб самовывоза, промокод (`GYM10`, `START15`), скидка члена клуба 10%, оформление |
| Мои заказы | История заказов со статусами выдачи |
| QR-пропуск | Обновляемый QR для турникета, статус абонемента |
| Абонемент | Тарифы 1/3/6/12 мес и дневной, заморозка, Kaspi / карта / рассрочка |
| Мои записи | Предстоящие и прошедшие, отмена |
| Прогресс | Календарь посещений за 8 недель, график веса, последние визиты |
| Профиль | Статистика, достижения, домашний клуб, настройки, выход |

Данные пока моковые (`src/data/mock.ts`), состояние хранится локально через AsyncStorage.

## Запуск на телефоне

1. Установите **Expo Go** из App Store / Google Play.
2. В папке проекта:

```bash
npx expo start
```

3. Отсканируйте QR-код камерой iPhone (или из Expo Go на Android). Телефон и компьютер должны быть в одной Wi-Fi сети. Если сеть не пропускает, используйте `npx expo start --tunnel`.

```bash
npx tsc --noEmit
npx expo lint
npx expo-doctor
```

## Сборка для магазинов (без Mac)

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform ios
npx eas-cli@latest build --platform android
```

Для iOS потребуется аккаунт Apple Developer (99 $/год). EAS собирает и подписывает приложение в облаке.

## Структура

```
src/
  app/              экраны (Expo Router)
    (tabs)/         5 вкладок: главная, клубы, расписание, тренеры, профиль
    club/[id]       карточка клуба
    trainer/[id]    карточка тренера
    class/[id]      занятие и запись
    news/[id]       новость
    qr.tsx          QR-пропуск (модалка)
    membership.tsx  абонемент и оплата
    bookings.tsx    мои записи
    progress.tsx    прогресс
    auth.tsx        вход
  components/ui.tsx общие UI-компоненты
  constants/theme.ts цвета, отступы, радиусы
  data/mock.ts      клубы, тренеры, расписание, тарифы, новости
  store/app-context.tsx состояние приложения + AsyncStorage
```
