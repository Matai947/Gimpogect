# Gym Project — мобильное приложение фитнес-сети

Клиентское приложение сети тренажёрных залов в духе FitnessBlitz / Fitnation / 1Fit:
абонемент, QR-вход, расписание групповых, запись к тренерам, загруженность клубов, прогресс.

Стек: **Expo SDK 57 · React Native · TypeScript · Expo Router**. Работает на iPhone и Android.

Интерфейс на трёх языках: русский, казахский, английский. Переключатель на экране входа и в профиле, выбор сохраняется. Словари лежат в `src/i18n/` (`ru.ts`, `kk.ts`, `en.ts` для интерфейса, `data.ts` для категорий, услуг и тарифов). ИИ-тренер с ключом API отвечает на выбранном языке; офлайн-библиотека техники пока на русском.

Нижняя панель: Главная, Клубы, Расписание, ИИ-тренер, Магазин, Профиль.

## Экраны

| Экран | Что умеет |
| --- | --- |
| Вход | Телефон + SMS-код (демо-код `1234`), имя |
| Анкета | Цель (похудеть, масса, форма, сила, гибкость), пол, возраст, рост, вес, целевой вес, уровень, тренировок в неделю; ИМТ считается на лету. Данные используются на главной, в профиле, прогрессе и магазине |
| Главная | Карточка абонемента с днями до конца, QR-пропуск, быстрые действия, ближайшие записи, загруженность клубов, новости |
| Клубы | Поиск, фильтр по городу, избранное, загруженность в реальном времени, 24/7 |
| Клуб | Фото, маршрут, звонок, инфраструктура, занятия сегодня, тренеры клуба, «сделать домашним» |
| Расписание | Лента дат на 14 дней, фильтры по клубу и направлению, свободные места |
| Занятие | Тренер, клуб, уровень, места, запись / отмена, лист ожидания |
| Тренеры | Поиск, специализации, рейтинг, цена; запись на персональную тренировку |
| ИИ-тренер | Чат с Claude, который знает анкету, вес и посещения: план на неделю в формате JSON, адаптация под «сухое тело» или набор, техника 21 упражнения пошагово, питание. Без ключа API работает офлайн-режим с базовым планом и библиотекой техники |
| Магазин | Спортпит, витамины, батончики, напитки, аксессуары, одежда; категории, поиск, сортировка, хиты |
| Товар | Фото, цена и цена по абонементу, вкус/размер, пищевая ценность, похожие товары, корзина |
| Корзина | Количество, клуб самовывоза, промокод (`GYM10`, `START15`), скидка члена клуба 10%, оформление |
| Мои заказы | История заказов со статусами выдачи |
| QR-пропуск | Обновляемый QR для турникета, статус абонемента |
| Абонемент | Тарифы 1/3/6/12 мес и дневной, заморозка, Kaspi / карта / рассрочка |
| Мои записи | Предстоящие и прошедшие, отмена |
| Прогресс | Календарь посещений за 8 недель, график веса, последние визиты |
| Профиль | Статистика, достижения, домашний клуб, настройки, выход |

Данные пока моковые (`src/data/mock.ts`), состояние хранится локально через AsyncStorage.

## Запуск на телефоне

1. Установите **Expo Go** из App Store / Google Play.
2. В папке проекта:

```bash
npx expo start
```

3. Отсканируйте QR-код камерой iPhone (или из Expo Go на Android). Телефон и компьютер должны быть в одной Wi-Fi сети. Если сеть не пропускает, используйте `npx expo start --tunnel`.

## Режим сотрудника

Вход по служебному коду (демо `2468`) со ссылки «Вход для сотрудников» на экране входа или из профиля. Сотрудник выбирает клуб смены и получает свои вкладки:

| Экран | Что умеет |
| --- | --- |
| Сканер | Камера читает QR участника (пропуск) и QR заказа (выдача). Ручной ввод телефона, ID или номера заказа. Карточка участника: абонемент, срок, визиты, решение «пропустить / отказать» с причиной (истёк, заморожен, дневной после 17:00, нет абонемента). Все проходы пишутся в журнал |
| Сегодня | Проходы и отказы за смену, занятия и заказы к выдаче, загруженность клуба, последние проходы |
| Занятия | Занятия клуба на сегодня, список записавшихся, отметка посещаемости |
| Заказы | Заказы магазина по клубу: «Готовится» → «Готов к выдаче» → «Выдан» |
| Товары | Управление каталогом магазина: добавить товар, отредактировать базовый, скрыть и восстановить, переключить наличие. Фото с камеры, из галереи или по ссылке, варианты вкуса/размера/цвета, метки, пищевая ценность. Изменения сразу видны участникам |
| Участники | Поиск и фильтры (активные, истекают, истекли, заморожены), карточка с пропуском |

У участника на карточке заказа в «Моих заказах» появляется QR для выдачи. Камера работает на телефоне через `expo-camera`; в браузере доступен только ручной ввод.

## ИИ-тренер и ключ API

ИИ-тренер использует модель `claude-opus-5-5` через `@anthropic-ai/sdk`. Ключ можно задать двумя способами:

- скопировать `.env.example` в `.env` и вписать `EXPO_PUBLIC_ANTHROPIC_API_KEY`, затем перезапустить `npx expo start`;
- или ввести ключ прямо в приложении: экран «ИИ-тренер», иконка ключа. Он хранится только на устройстве.

Без ключа тренер работает в офлайн-режиме: базовый план по шаблонам и техника упражнений из `src/data/exercises.ts`. Для продакшена ключ нельзя оставлять в приложении, запросы должны идти через ваш сервер.

## Структура

```
src/
  app/              экраны (Expo Router)
    (tabs)/         6 вкладок: главная, клубы, расписание, ИИ-тренер, магазин, профиль
    club/[id]       карточка клуба
    trainer/[id]    карточка тренера
    class/[id]      занятие и запись
    news/[id]       новость
    qr.tsx          QR-пропуск (модалка)
    membership.tsx  абонемент и оплата
    bookings.tsx    мои записи
    progress.tsx    прогресс
    auth.tsx        вход
  components/ui.tsx общие UI-компоненты
  i18n/             переводы RU / KZ / EN
  constants/theme.ts цвета, отступы, радиусы
  data/mock.ts      клубы, тренеры, расписание, тарифы, новости
  store/app-context.tsx состояние приложения + AsyncStorage
```
